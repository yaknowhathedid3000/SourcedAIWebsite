# App Store listing

Character counts are hard limits. Anything over is rejected at submission, so
the numbers here are checked, not estimated.

## Name (24/30)

```
Yogi: Save & Actually Do
```

Apple indexes the name most heavily of any field. "Save" is the search term
people actually type; "Actually Do" is the differentiator and the brand line.

## Subtitle (26/30)

```
Your saves, finally useful
```

## Keywords (93/100)

```
bookmark,saved,reels,tiktok,recipe,link,organize,later,screenshot,collection,travel,list,plan
```

Rules this follows, which are the ones people break:

- Comma separated, **no spaces after commas**. A space costs a character.
- Never repeat words already in the name or subtitle. Apple indexes those
  fields, so repeating burns the 100 characters twice.
- Singular only. Apple matches plurals automatically.
- No competitor names. It is against the guidelines and gets listings pulled.

## Promotional text (105/170)

Editable without shipping a build, so use it for whatever is newest.

```
New: turn saved reels into a trip. Yogi finds every place you saved from TikTok and puts them on one map.
```

## Description

Only the first three lines show before "more", so they carry the weight.

```

Yogi is the part that comes after saving. Send it any link, reel or

SEND IT ONCE
```

## What to get right before submitting

- **First three lines of the description.** Almost nobody taps "more".
- **Screenshots 1 to 3.** They appear in search results. Treat them as the ad.
- **The subtitle.** It is indexed and it is the only line under your name.
- Promotional text can be changed any time without a build. Description cannot,
  it needs a new version.
